# Páginas web

Esta carpeta se publica con GitHub Pages en `https://silvia-mov.github.io/nomenclaturas-y-correlaciones-del-mercosur/`.

| Archivo | Qué es |
|---|---|
| `listas.html` | Listas de la nomenclatura: BK, BIT, LNE y materias primas de Paraguay, con buscador y descargas |
| `datos/listas.json` | Datos del buscador (lo arma `python/web_listas.py`) |
| `img/` | Imágenes de la tarjeta de la página principal |

Para publicarla: en GitHub, *Settings > Pages*, elegir la rama `main` y la carpeta `/docs`.
